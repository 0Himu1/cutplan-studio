# Phase 21 — marketing landing and final content

Status: local implementation complete, 23 October 2026. Owner visual acceptance and production publication remain pending.

The root page is now a distinct full-width marketing surface; project/account/order pages retain the studio shell. The original headline, paired dark/light theme and Inter family remain. A calculated open-cabinet schematic responds to Explode/Assemble without changing a project. Sparse connected indigo particles are decorative, limited to 20 frames/second and pause when hidden or offscreen; reduced motion and limited-core devices disable the animation. The animation has no scroll-triggered reveals.

Try it out and family links enter the existing guest creation flow. Recent projects remain on the home page, so returning users retain access to their drafts. The fixed CAD viewport is unchanged. Landing copy states the planned Dhaka offer, unapproved service areas/commercial terms, current design capabilities and closed live ordering. No fake prices, delivery promises, load ratings or payment claims were added.

Page title, description and Open Graph metadata are added. Studio sidebar/global description also describe the Dhaka offer as planned, rather than implying live delivery. SVG accessible titles use one text node to preserve correct React server hydration. Search indexing intentionally remains disabled in metadata and `robots.txt` until deployment/launch approval; no canonical production domain was invented. This is SEO preparation, not a public-indexing or deployment claim.

Responsive dark/light, reduced-motion, explode/reassemble and entry-flow screenshots are under `artifacts/review/phases-20-22/`. Desktop and mobile/light captures were visually inspected.
