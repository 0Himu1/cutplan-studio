# Account projects and revision history

Mode: Operate. This surface inherits the approved CutPlan Studio world and the Phase 4 direction in `docs/design/phase-04-cloud-projects.md`.

## Direction contract

THESIS: Account saves are deliberate, versioned and recoverable.

OWN-WORLD: Existing Inter, paired themes, indigo actions, flat borders, Lucide icons and furniture schematics.

STORY: Save a browser draft, reopen the account copy, rename it as a new revision, inspect history, retry interruptions.

FIRST VIEWPORT: Project name, storage state and current version lead; recovery never hides below decorative content.

FORM: Scoped extension; seed: none. Preserve current shell, breakpoints and Tailwind vocabulary.

SIGNATURE: Plain-language revision and sync status, with typed conflict input preserved until explicit reload.
