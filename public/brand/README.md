# Google sign-in artwork

`google-sign-in.svg` is the unmodified Android + Web, Light, Square, Show text=Yes SVG from Google's official https://developers.google.com/static/identity/images/signin-assets.zip download, referenced by https://developers.google.com/identity/branding-guidelines.

It includes outlined text and the official color logo. Keep its aspect ratio, artwork and label intact. It is provider branding, not a new CutPlan design-system color or font. No Google Identity script, tracking SDK or remote image request is loaded by this asset.
