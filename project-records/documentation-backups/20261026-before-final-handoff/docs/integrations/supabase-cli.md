## Commands

```powershell
npm run supabase -- --version
npm run db:migrations
npm run db:plan
npm run db:query -- "select current_user;"
npm run supabase -- migration new descriptive_change
npm run supabase -- db push --linked --dry-run
npm run supabase -- db push --linked
```

Keep schema changes in reviewed files under `supabase/migrations`. Check the linked project and dry-run plan before a push. The browser-applied Phase 3 migration is already recorded; do not run it again as ad hoc SQL. Phase 4 migrations have not been created or applied by this setup.

The installed CLI supports linked SQL queries, migration management, type generation and database inspection. Remote queries and migrations work without starting the local Docker stack. Docker-dependent local database, diff or dump workflows have not been provisioned or verified here.
