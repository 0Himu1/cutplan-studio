# Phases 18–19 — reviewed commands and synthetic production inspection

Preserve the Precision CAD canvas, Inter typography, existing dark surfaces and indigo actions. Commands are a short overlay reached through Inspect or context actions; no extra header button crowds tablet/mobile controls. The compact diff shows changed dimensions/shelves and explicit Apply/Discard. Requests never mutate state before review. Single transaction history, explicit Save, stale configuration checks and existing family/material validation remain authoritative.

Production review is a separate studio page with a fixed synthetic fixture. It uses existing theme surfaces/borders, amber simulation status, left-aligned operational text and blue/amber sheet paths. Code inspection uses ten-line pages; sheet changes reset the line page. It does not turn a customer project into a manufacturing workstation or introduce scrolling into the CAD editor.

The production report includes reproducible frozen inputs and hashes. Only a JSON simulation report can be downloaded. A persistent release gate and separate staff qualification surface explain the real requirements. No customer, operator or admin can obtain live machine files from the current implementation.

Durable-job SQL is applied following explicit owner instruction. The hosted worker/queue is not activated. Awaiting-profile snapshots remain immutable; future profile-specific jobs require a separately reviewed qualified flow. Synthetic parser checks are deliberately distinct from controller and physical qualification. The original 22-phase numbering remains unchanged; Phase 20 inherits exact accepted part identities and outstanding hardware/construction approval.
